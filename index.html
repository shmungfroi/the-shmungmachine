Start simple, then deepen

Book 1 · Compose

  1. Record environmental, vocal or instrumental sounds onto the pads.
  2. Create a four-cell library and map one sample across the keyboard.
  3. Build a 16-step pattern or perform the pads freely.
  4. Add a contrasting synth layer only when it supports the sound world.
  5. Export the raw pattern and retain the project file.

Book 2 · Transform

  1. Reload the same project.
  2. Shape the spectrum with filters.
  3. Create space and dialogue with delay and reverb.
  4. Use chorus, distortion and compression deliberately.
  5. Perform over the project in Daybreak mode and export the refined version.
Keyboard controls: Z–, and Q–I play two chromatic octaves. Space starts or stops the global transport when focus is not inside a text field.
Project safety: download a project file at the end of each lesson. Browser local storage should be treated as a convenience, not the only copy.
